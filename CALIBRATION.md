# Контрольные траектории NSRC

7 ноября 2026 года запущен локальный набор из восьми решаемых задач и
двух сценариев для проверки пропуска. Запуск шёл в конкурсном Docker-образе через
NeuralDeep. Код для повторения: `calibration_run.py`; ключ передаётся только
через `LLM_API_KEY`. Ответы проверены по данным, созданным этим скриптом.

| Тип | Задача | Прогноз, приведённых токенов | Факт | Результат |
| --- | --- | ---: | ---: | --- |
| Математика | `math_a` | 21,9 | 10,5 | верно |
| Математика | `math_b` | 15,4 | 10,8 | верно |
| Поиск | `search_a` | 21,3 | 13,6 | верно |
| Поиск | `search_b` | 23,8 | 14,5 | верно |
| Код | `coding_a` | 91,6 | 47,9 | тесты прошли |
| Код | `coding_b` | 77,4 | 74,8 | тесты прошли |
| CSV | `data_a`, `data_b` | 0 | 0 | верно локально |
| Контрольные пропуски | `search_missing`, `coding_contradict` | 0 | 0 | пропущены до API |

На шести задачах, требовавших модель, суммарный прогноз составил 251,4 токена,
фактический расход — 172,1. На этом наборе суммарный прогноз выше расхода;
это не доказывает отсутствие недооценки отдельных или новых задач.
Набор применялся при настройке констант и локальных шаблонов, поэтому это
**проверка работоспособности, а не независимая оценка качества предиктора**.
Все задачи короткие, а сложность скрытых задач неизвестна. Срабатывание skip
на двух сценариях не подтверждает корректность правил на других форматах;
риски разобраны в [HARNESS_RESEARCH.md](HARNESS_RESEARCH.md).
Во время прогона харнесс записывает отдельные вызовы, расходы и
неудачи в JSONL и обновляет оценки стоимости по типам задач.

Отдельный пробный запрос `2+2` показал 143,8 приведённого токена на
`qwen3.6-35b-a3b` и 35,4 на `qwen3.8-27b`. Один запрос не позволяет надёжно
сравнить модели по всем типам задач. Сейчас reasoning-повторы отбираются
эвристически по награде и остатку бюджета; их дополнительный ожидаемый выигрыш
ещё не оценивается обученной моделью.

Примечание 12 ноября: прежний контроль `search_missing` не доказывал невыполнимость. Жёсткие пропуски по именам файлов/колонок удалены из планировщика; старые цифры выше относятся к прежней версии. Новый независимый эксперимент описан в `experiments/README.md`; бюджет разработки — 100k на каждую модель.
