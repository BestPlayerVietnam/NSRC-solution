# NSRC — openJiuwen Challenge

## Задача

Набрать максимальную сумму баллов на наборе из 100 задач при общем бюджете токенов. Задачи охватывают математику, исправление Python-кода, поиск в локальных документах и анализ CSV. Набор содержит выполнимые и невыполнимые задания. Баллы указаны в поле `reward` каждого `task.json`.

## Решение

- Калькулятор, SQLite, поиск по файлам и проверка Python-кода выполняют вычисления и проверяют результаты локально.
- Регрессионный предиктор оценивает расход первого запроса и полного решения по типу задачи, длине условия и контекста, размерам исходников и публичных тестов. Артефакт `cost_artifact.json` обучен на собственных траекториях конкурсных моделей. Проверка применимости прогноза выбирает регрессионную или эвристическую оценку.
- Очередь ранжируется по `reward × P(успеха) / ожидаемый расход`. Наблюдаемый расход уточняет прогнозы следующих задач.
- Анализ условий и публичных контрактов выявляет доказанные противоречия. Самооценка модели, обратная связь инструментов и наличие нового шага определяют продолжение, перенос задачи или остановку повторов.
- Память подтверждённых инструментальных исправлений передаёт полезный опыт следующим задачам текущего запуска.

Запросы к модели проходят через openJiuwen и API-прокси из окружения. По умолчанию используется `qwen3.8-27b`.

Расход считается как `0,1 × входные токены + выходные токены`, включая reasoning. Перед каждым физическим запросом резервируется его стоимость. Ответ API уточняет фактический расход общего бюджета.

## Запуск

Установите Docker с Docker Compose. На Windows используйте Docker Desktop с поддержкой Linux-контейнеров.

Скопируйте [.env.example](.env.example) в `.env` и заполните параметры подключения и запуска.

| Переменная | Значение |
| --- | --- |
| `LLM_BASE_URL` | Адрес API-прокси |
| `LLM_API_KEY` | Ключ API |
| `BUDGET` | Общий бюджет приведённых токенов |
| `TASKS_DIR` | Путь к каталогу задач |

Разместите задания по пути `<TASKS_DIR>/<task_id>/task.json`. Рабочие файлы размещаются в каталоге задачи или его подкаталоге `workspace`.

Запустите из корня проекта.

```sh
docker compose run --build --rm agent
```

На Windows можно открыть [start.cmd](start.cmd) двойным щелчком.

## Результаты

Ответ сохраняется сразу в `answer.txt` в каталоге задачи и её рабочем каталоге. Для Python-задач сохраняются исправленные исходники и ответ `DONE` после прохождения публичных тестов. Каталоги с существующим `answer.txt` считаются завершёнными. Для повторного прогона используйте свежую копию входных данных.

Траектории записываются в `<TASKS_DIR>/nsrc-trajectory.jsonl`. Каждая строка содержит событие задачи. Для обращений к модели сохраняются прогноз токенов, учтённый расход и usage API, длительность, решения о повторах, самооценка и итог проверки. Локальные решения и доказанные противоречия отражаются отдельными событиями.
